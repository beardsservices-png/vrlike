      How to read the plan

      • One square = one blockColumns run left to right on the grid, rows top to bottom. On the truck, col 1 is the bull bar and row 1 is the passenger side. Thick lines every 10.
      • Starting blockCol 1, row 1, layer 1 is the corner everything is measured from. It's the red post in the 3D view and the red square on layer 1.
      • TV build modeShows one row at a time, big. Tap "Done, next row" after each one; it remembers where you stopped.
      • From a pictureAdd any PNG or JPG and it becomes a block build, saved in this browser. Transparent parts of a PNG are left empty.
      • From Draft StudioIn Draft Studio, export STL or OBJ, then add that file here with "From a picture or 3D file". It comes in at its real size; pick how many inches each block is.
      • Skip hidden blocksLeaves out blocks nobody can see from outside, so solid shapes are built as shells.
      • CommandsWith the starting block filled in, TV build mode gives a ready /fill command for each run, so one command places a whole line. All the commands are in the Bedrock Command Guide.
      • Glass sits flushUse full stained-glass blocks, not panes.
